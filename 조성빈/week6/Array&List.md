# 배열(Array)과 리스트(List), 연결 리스트(Linked List)

## 1. 개요 (Overview)

파이썬의 `list`는 엄밀히 말하면 **동적 배열(Dynamic Array)**입니다. 다른 언어의 배열과 리스트의 장점을 결합한 형태입니다.

---

## 2. 배열 (Array)

- 선형 자료구조
- 메모리상 **연속적으로** 데이터가 저장되는 구조

### 특징

- 선언할 때 크기를 미리 정해야 하며, 나중에 크기를 변경할 수 없습니다.
- 모든 요소가 물리적으로 붙어 있어 인덱스를 통한 접근이 매우 빠릅니다.

### 장점

- 인덱스만 알면 $O(1)$의 시간 복잡도로 즉시 데이터를 찾을 수 있습니다.

### 단점

- 데이터를 삽입하거나 삭제할 때, 빈 공간을 만들거나 채우기 위해 다른 요소들을 옆으로 밀어야 하므로 비효율적($O(n)$)입니다.
- 메모리 낭비가 발생할 수 있습니다 (미리 크게 잡아놓은 경우).

---

## 3. 연결 리스트 (Linked List)

연결 리스트는 데이터(Node)들이 메모리상에 흩어져 있으며, 각 노드가 다음 노드의 주소(포인터)를 저장하여 서로 연결하는 방식입니다.

### 특징

- 크기가 동적으로 변할 수 있습니다.
- 데이터와 포인터를 함께 저장하므로 배열보다 메모리 사용량이 약간 더 많습니다.

### 장점

- 중간에 데이터를 삽입하거나 삭제할 때 포인터만 바꿔주면 되므로 배열보다 빠릅니다.

### 단점

- 특정 위치의 데이터를 찾으려면 첫 번째 노드부터 순차적으로 따라가야 하므로 탐색 속도가 느립니다.

---

## 4. 배열(Array) vs 리스트(List) 비교

| 특징            | 전통적인 배열 (Static Array)     | 파이썬 리스트 (List / Dynamic Array)  |
| :-------------- | :------------------------------- | :------------------------------------ |
| **크기 결정**   | 선언 시 고정 (Static)            | 실행 중 유동적으로 변경 (Dynamic)     |
| **데이터 타입** | 동일한 타입만 저장 가능          | 다양한 타입을 섞어서 저장 가능        |
| **메모리 저장** | 물리적으로 연속된 공간에 값 저장 | **참조값(주소)**을 연속된 공간에 저장 |
| **장점**        | 구조가 단순하고 접근이 매우 빠름 | 사용이 편리하고 유연함                |

---

## 5. 파이썬 리스트의 특징

### ① 참조 기반 저장

파이썬 리스트는 실제 값을 직접 저장하는 것이 아니라, 값이 저장된 메모리 위치를 가리키는 **포인터(Reference)**를 저장합니다. 이 때문에 리스트에 다양한 자료형을 담을 수 있습니다.

### ② 동적 할당 (Resizing)

리스트의 용량이 꽉 차면, 파이썬은 더 큰 메모리 공간을 새로 할당하고 기존 데이터를 복사합니다. 이 과정이 가끔 발생하므로 `append()`의 시간 복잡도는 **분할 상환 $O(1)$**로 계산합니다.

---

## 6. 코딩 테스트 필수 시간 복잡도

| 연산                | 시간 복잡도   | 설명                                      |
| :------------------ | :------------ | :---------------------------------------- |
| **Indexing**        | $O(1)$        | `arr[i]`                                  |
| **Append**          | $O(1)$        | 끝에 추가 (가장 빠름)                     |
| **Pop (last)**      | $O(1)$        | 끝에서 제거                               |
| **Insert / Pop(0)** | $O(N)$        | 중간/앞에 추가 및 삭제 (데이터 이동 발생) |
| **Slicing**         | $O(k)$        | `arr[a:b]` (범위 $k$ 만큼 복사)           |
| **Search**          | $O(N)$        | `value in arr` (전수 조사)                |
| **Sort**            | $O(N \log N)$ | Timsort 알고리즘 사용                     |

---

## 7. 코테 실전 팁 (Best Practices)

### ① 리스트 대신 `deque` 사용하기

- 문제에서 **앞쪽 데이터의 삽입/삭제**가 빈번하다면 `list.pop(0)` 대신 `collections.deque`의 `popleft()`를 사용하세요.
- `list.pop(0)`은 $O(N)$이지만, `deque.popleft()`는 $O(1)$입니다.

### ② 리스트 컴프리헨션 (List Comprehension)

- 가독성과 속도 면에서 일반적인 `for` 루프보다 권장됩니다.

```python
# 0부터 9까지 짝수만 담긴 리스트 생성
even_list = [i for i in range(10) if i % 2 == 0]
```
